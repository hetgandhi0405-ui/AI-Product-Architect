# Requirements — Website Uptime Monitoring Platform

## Objective
Http(s) monitor registration, synthetic check results, uptime history; no live check by default.

## Functional requirements
- Http(s) monitor registration.
- Synthetic check results.
- Uptime history; no live check by default.

## Non-functional requirements
- Validate inputs server-side.
- Provide health and OpenAPI endpoints.
- Keep secrets out of source control.
- Add persistent storage, access controls, and observability before production.
