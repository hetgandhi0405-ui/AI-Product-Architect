# Requirements — Real-Time Analytics Dashboard

## Objective
Event ingestion, event listing, aggregated metrics, synthetic demo data.

## Functional requirements
- Event ingestion.
- Event listing.
- Aggregated metrics.
- Synthetic demo data.

## Non-functional requirements
- Validate inputs server-side.
- Provide health and OpenAPI endpoints.
- Keep secrets out of source control.
- Add persistent storage, access controls, and observability before production.
