# UI/UX Specification — Personal Finance Tracker

## Visual design
- Professional responsive workspace with a dark navy navigation rail and light content canvas.
- Purple primary actions, blue information accents, white cards, subtle borders, and restrained shadows.
- Responsive metric cards, recent activity, table views, and mobile-friendly navigation.
- Accessible labels, keyboard-operable controls, readable contrast, and clear empty states.

## Screens
- Overview dashboard with metric cards and quick-create form.
- Transactions listing.
- Budgets listing.
- Insights, architecture overview, project file inventory, and quality checks.

## Frontend behavior
This frontend is a standalone UI/UX demonstration. It uses browser memory for sample interactions and contains no API URL fields, API connection controls, endpoint explorer, HTTP request tools, API status indicators, or direct backend calls.

## Limitations
Demo records are temporary and are not persisted or connected to the backend. The backend remains separately available in the project bundle.
